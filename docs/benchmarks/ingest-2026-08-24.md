# Ingest reference benchmarks — 2026-08-24

Reference profile: Apple M1 Pro, darwin/arm64, Go benchmark `benchtime=1x`.
The committed CI gate runs each corpus three times, compares the median with
these baselines, and fails above 120%.

| Corpus | Median | Allocated bytes | Allocations |
|---:|---:|---:|---:|
| 10K | 9.27 ms | 5,323,368 | 89,800 |
| 100K | 53.08 ms | 53,243,024 | 900,222 |
| 1M | 530.48 ms | 532,425,368 | 9,004,268 |

The executable acceptance gates also require an empty incremental run under two
seconds and a 1,000-record changed run below 500 MiB of total allocation. Total
allocation is a stricter ceiling than peak live heap for that bounded run.

Reproduce locally:

```bash
go test ./internal/memory -run '^$' -bench 'BenchmarkIngestCorpus(10K|100K|1M)$' -benchtime=1x -benchmem -count=3
MORA_ENFORCE_INGEST_BENCH=1 go test ./internal/memory -run 'TestIngestReferenceBenchmarkRegression|TestIncremental1000RecordsUnder500MB|TestIngestNoOpUnderTwoSeconds' -count=1
```
