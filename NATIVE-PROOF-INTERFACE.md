# Native proof private interface (v1)

This is a private child-stdio contract shared by the native adapters. It does
not expose a listener, MCP method, token, public key import, or caller-selected
identity. The Go authority establishes the trusted peer before reading a frame.

## Framing

Each request and response is one UTF-8 JSON object preceded by a four-byte
big-endian unsigned length. Frames larger than 1 MiB, truncated headers or
bodies, invalid UTF-8/JSON, or a schema/version mismatch are fatal to the
session. Every object includes `schema: "mora.review.desktop"` and
`schema_version: 1`.

## Operations

| Request `op` | Required fields | Response |
| --- | --- | --- |
| `list` | — | `notes` (the bounded pending queue) |
| `show` | `kind`, `id` | `preview` (canonical receipt) |
| `status` | — | `installation_id`, `enrolled`, `read_only` |
| `enroll.begin` | — for Windows WebAuthn; Mac supplies `public_key_p256_b64`, `credential_id` | opaque `challenge_bytes_b64`, `key_id`, `nonce` |
| `enroll.complete` | Windows: `nonce`, client data, authenticator data, credential ID; Mac: `nonce`, `signature_der_b64` | enrollment status |
| `enroll.cancel` | `nonce` | cancellation receipt |
| `decision.begin` | `action`, `kind`, `id`, `canonical_revision`, `display_digest` | opaque `challenge_bytes_b64` |
| `decision.complete` | `nonce`, `signature_der_b64` | mutation outcome |
| `cancel` | `nonce` | cancelled decision outcome |

Mac `enroll.begin` accepts only public material generated by the already-trusted
native peer. Windows instead receives the opaque creation challenge first, then
Go derives both credential ID and public key from the returned authenticator
data. The peer signs no rebuilt enrollment or decision byte strings. The
production Windows adapter must use this schema over Go-created private handles;
it must not authenticate a claimed parent PID, package, signer, path, or key.

## Platform proof envelope

The Mac v1 fields carry `public_key_p256` plus `signature_der` because the
signed app generates its Secure Enclave key and Go independently verifies DER
P-256. Windows is deliberately **not** a public-key fallback: its future
`enroll.complete` envelope carries the WebAuthn attestation/authenticator data,
and `decision.complete` carries client data, authenticator data, credential ID,
and assertion signature. Go derives and verifies its enrollment material from
that envelope only after launching the hash-pinned helper through its own
private handles. The unsupported Windows stub remains read-only until that
helper exists.

## Errors

Failures use `{ "error": { "code": "ERR_OWNER_VERIFICATION_UNAVAILABLE" |
"ERR_INVALID_REQUEST" | "ERR_REVIEW_UNAVAILABLE", "message": "safe text" } }`.
No error contains a file path, public key, challenge, environment value, or
process identity.
